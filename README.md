# EventManagement App

Application de gestion d'événements développée avec ASP.NET Core, permettant aux agences événementielles de gérer leurs événements et participants.

## 🛠 Technologies utilisées

- ASP.NET Core 7.0
- Entity Framework Core
- MongoDB.Driver
- Bootstrap 5
- ASP.NET Identity
- Gitflow Atlassian

## 📋 Features

Cette application offre une interface intuitive pour :

- Gérer les événements (création, modification, suppression)
- Gérer les participants
- Suivre les inscriptions aux événements
- Consulter des statistiques (WIP)

## 🎨 Maquettes

Les maquettes de l'application sont disponibles dans le fichier `ECF_EventManagement.fig` à la racine du projet.

## 🏗 Architecture

L'application utilise une architecture MVC avec :

- Base de données SQL Server pour les données principales
- MongoDB pour les statistiques
- ASP.NET Identity pour l'authentification

## 🚀 Installation

### Prérequis

- .NET 7.0 SDK
- SQL Server 2019+
- MongoDB 6.0+

### Configuration

1. Cloner le repository :

```bash
git clone https://github.com/ELMCode/EventManagement.git
cd EventManagement
```

2. Configurer la base de données SQL Server :
   - Modifier la chaîne de connexion dans `appsettings.json`
   - Exécuter les migrations :

```bash
dotnet ef database update
```

3. Configurer MongoDB (WIP) :
   - Modifier la chaîne de connexion MongoDB dans `appsettings.json`

## 🏃‍♂️ Démarrage

1. Lancer l'application :

```bash
dotnet run
```
